# 人工智能核心知识库

## 一、人工智能概述

人工智能（Artificial Intelligence, AI）是研究、开发用于模拟、延伸和扩展人类智能的理论、方法、技术及应用系统的一门技术科学。AI 可分为弱人工智能（窄 AI，专注特定任务）和强人工智能（通用 AI，具备人类级别的通用智能）。目前实际应用的均为弱人工智能。

机器学习是 AI 的核心子领域，强调让机器从数据中自动学习规律，而非依赖显式编程规则。深度学习是机器学习的一个分支，基于多层人工神经网络，擅长处理图像、语音、文本等非结构化数据。

AI 的主要研究方向包括：机器学习、深度学习、自然语言处理、计算机视觉、语音识别、知识图谱、推荐系统、强化学习、机器人学等。

## 二、机器学习基础

机器学习按学习方式可分为三类：监督学习（Supervised Learning）使用带标签数据训练，学习输入到输出的映射；无监督学习（Unsupervised Learning）处理无标签数据，发现数据内在结构；强化学习（Reinforcement Learning）通过与环境交互获得奖励信号来学习策略。

监督学习的典型任务包括分类（预测离散标签）和回归（预测连续值）。无监督学习的典型任务包括聚类（将相似样本分组）和降维（减少特征维度）。

机器学习的一般流程：数据收集 → 数据清洗 → 特征工程 → 模型选择 → 模型训练 → 模型评估 → 模型部署。特征工程是传统机器学习中最重要的环节，直接决定模型性能上限。

## 三、监督学习经典算法

线性回归（Linear Regression）是最基础的回归模型，假设输入与输出呈线性关系，通过最小化均方误差（MSE）求解参数。形式为 y = w^T x + b。损失函数为 MSE = (1/n)Σ(y_i - ŷ_i)²。

逻辑回归（Logistic Regression）用于二分类，通过 sigmoid 函数将线性输出映射到 [0,1] 概率。sigmoid(x) = 1/(1+e^-x)。损失函数为交叉熵损失。虽然叫"回归"，但实际是分类模型。

决策树（Decision Tree）通过树形结构进行决策，内部节点表示特征测试，叶节点表示类别。常用算法有 ID3（信息增益）、C4.5（信息增益率）、CART（基尼指数）。决策树易过拟合，需剪枝。

支持向量机（SVM）通过寻找最大间隔超平面来分类。核心思想是最大化分类间隔，对小样本高维数据效果好。核技巧（Kernel Trick）可处理非线性问题，常用核函数有线性核、RBF 核、多项式核。

K 近邻（KNN）是一种惰性学习算法，预测时查找 K 个最近邻居，多数投票决定类别。无需训练过程，但预测慢。K 值太小易过拟合，太大易欠拟合。

朴素贝叶斯（Naive Bayes）基于贝叶斯定理和特征条件独立假设。P(y|x) ∝ P(x|y)P(y)。"朴素"假设各特征相互独立。计算高效，适合文本分类。

集成学习（Ensemble Learning）通过组合多个弱学习器提升性能。主要有 Bagging（如随机森林，并行训练，降低方差）和 Boosting（如 AdaBoost、GBDT、XGBoost，串行训练，降低偏差）。

随机森林（Random Forest）是 Bagging 的代表，构建多棵决策树，每棵树随机选择特征和样本，最终投票或平均。抗过拟合能力强，应用广泛。

XGBoost 是 Gradient Boosting 的高效实现，通过正则化、列采样、缺失值处理等优化，在结构化数据竞赛中长期占据统治地位。

## 四、无监督学习

K-Means 是最常用的聚类算法，通过迭代将数据分为 K 个簇。步骤：随机初始化 K 个质心 → 分配样本到最近质心 → 更新质心 → 重复直到收敛。K 值需预先指定，对初始质心敏感。

主成分分析（PCA）是线性降维方法，通过正交变换将高维数据投影到低维空间，保留最大方差方向。步骤：中心化 → 计算协方差矩阵 → 特征值分解 → 取前 K 个特征向量。

层次聚类（Hierarchical Clustering）通过递归合并或分裂构建聚类树。凝聚式（自底向上）最常用，每次合并最相似的两个簇。无需预先指定簇数，但计算复杂度高。

## 五、深度学习基础

人工神经网络由多层神经元组成，每个神经元计算 z = w^T x + b，再经激活函数输出。激活函数引入非线性，使网络能拟合复杂函数。

常用激活函数：Sigmoid（输出 [0,1]，易梯度消失）、Tanh（输出 [-1,1]，比 sigmoid 好）、ReLU（f(x)=max(0,x)，当前最常用，缓解梯度消失）、Leaky ReLU（负半轴有小斜率）、GELU（Transformer 中常用）。

反向传播（Backpropagation）是训练神经网络的核心算法，基于链式法则计算损失对各参数的梯度，再用梯度下降更新参数。前向传播计算输出和损失，反向传播计算梯度。

损失函数：回归用 MSE，分类用交叉熵。交叉熵 L = -Σ y_i log(p_i)，衡量预测分布与真实分布的差异。多分类用 softmax 交叉熵。

优化器：SGD（随机梯度下降）、Momentum（带动量）、RMSProp、Adam（结合动量和自适应学习率，最常用）。Adam 通过一阶矩和二阶矩估计自适应调整每个参数的学习率。

学习率是最重要的超参数之一。太大不收敛，太小收敛慢。常用学习率调度：StepLR（按步长衰减）、CosineAnnealing（余弦退火）、Warmup（预热）。

## 六、深度学习经典网络

卷积神经网络（CNN）擅长处理图像。核心组件：卷积层（提取局部特征）、池化层（降维）、全连接层。经典 CNN：LeNet、AlexNet、VGG、GoogLeNet、ResNet。

ResNet 引入残差连接（Residual Connection），解决深层网络退化问题。残差块：y = F(x) + x，让网络学习残差而非直接映射。ResNet 使训练上百层网络成为可能。

循环神经网络（RNN）处理序列数据，隐藏状态在时间步间传递。但 RNN 易梯度消失，难以捕捉长距离依赖。LSTM 和 GRU 通过门控机制缓解此问题。

LSTM（长短期记忆网络）包含遗忘门、输入门、输出门，控制信息流动。能有效捕捉长距离依赖，广泛用于 NLP 和语音。GRU 是 LSTM 的简化版，参数更少。

Transformer 完全基于自注意力机制（Self-Attention），摒弃 RNN 的循环结构，可并行计算。核心是注意力：Attention(Q,K,V) = softmax(QK^T/√d_k)V。Transformer 是当前大模型的基础架构。

多头注意力（Multi-Head Attention）将 Q,K,V 投影到多个子空间，分别计算注意力再拼接，捕获不同子空间的信息。位置编码（Positional Encoding）为序列注入位置信息。

## 七、训练技巧与常见问题

梯度消失：深层网络中梯度在反向传播时逐层指数衰减，导致前层参数无法更新。解决方案：ReLU 激活、残差连接、BatchNorm、LSTM、梯度裁剪。

梯度爆炸：梯度过大导致训练不稳定。解决方案：梯度裁剪（clip）、合理初始化、BatchNorm。

过拟合：模型在训练集表现好但测试集差。解决方案：增加数据、数据增强、正则化（L1/L2）、Dropout、早停（Early Stopping）、减少模型复杂度。

Dropout 训练时随机将部分神经元输出置零，防止神经元共适应，起到正则化作用。测试时恢复全部神经元。

Batch Normalization（BN）对每个 mini-batch 的特征做归一化，使分布稳定，加速训练，允许更大学习率。但 BN 对 batch size 敏感，小 batch 可用 LayerNorm。

数据增强：通过旋转、翻转、裁剪、加噪声等方式扩充训练数据，提升泛化能力。NLP 中可用同义词替换、回译等。

## 八、模型评估

分类指标：准确率（Accuracy）= 正确预测数/总数。精确率（Precision）= TP/(TP+FP)，预测为正的样本中真正为正的比例。召回率（Recall）= TP/(TP+FN)，真正为正的样本中被预测为正的比例。

F1 分数是精确率和召回率的调和平均：F1 = 2·P·R/(P+R)，综合衡量。AUC 是 ROC 曲线下面积，衡量模型整体排序能力，不受阈值影响。

混淆矩阵展示分类结果，行是真实类别，列是预测类别。TP（真正例）、TN（真负例）、FP（假正例）、FN（假负例）。

回归指标：MSE（均方误差）、MAE（平均绝对误差）、RMSE（均方根误差）、R²（决定系数，衡量模型解释方差的比例）。

交叉验证：将数据分为 K 折，轮流用 K-1 折训练、1 折验证，取平均性能。K 通常取 5 或 10。更可靠地评估模型泛化能力。

## 九、自然语言处理

词向量（Word Embedding）将词语映射为稠密向量，捕捉语义相似性。Word2Vec（CBOW 和 Skip-gram）、GloVe 是经典方法。词向量是 NLP 的基础表示。

Seq2Seq 模型由编码器（Encoder）和解码器（Decoder）组成，处理输入序列到输出序列的任务（如机器翻译）。常结合注意力机制。

BERT 是双向预训练语言模型，通过 Masked LM 和 Next Sentence Prediction 预训练，再微调下游任务。BERT 开启了 NLP 的预训练时代。

GPT 系列是自回归语言模型，从左到右生成文本。GPT-3、GPT-4 等通过扩大参数规模和训练数据，展现出强大的通用能力，是大语言模型的代表。

Tokenization 是 NLP 的预处理步骤，将文本切分为 token。常见方法：BPE（字节对编码）、WordPiece、SentencePiece。大模型普遍使用 BPE 类分词。

## 十、计算机视觉

目标检测定位并识别图像中的多个物体。经典方法：R-CNN 系列（两阶段）、YOLO 系列（一阶段，速度快）、SSD。YOLO 因速度快广泛用于实时检测。

图像分割将图像像素分为不同类别。语义分割（每个像素分类）、实例分割（区分同类不同实例）。代表模型：FCN、U-Net、Mask R-CNN。

图像分类是 CV 基础任务，将图像分到预定义类别。ImageNet 是著名的大规模图像分类数据集，推动了 CNN 发展。

## 十一、大语言模型

预训练（Pre-training）：在大规模无标注文本上训练语言模型，学习通用语言知识。微调（Fine-tuning）：在特定任务数据上继续训练，适配下游任务。

Prompt Engineering 是通过设计输入提示来引导大模型输出的技术。技巧包括：明确指令、提供示例（Few-shot）、角色设定、思维链（Chain-of-Thought）分步推理。

RLHF（基于人类反馈的强化学习）通过人类排序数据训练奖励模型，再用强化学习（PPO）优化语言模型，使输出更符合人类偏好。是 ChatGPT 等模型对齐人类价值观的关键技术。

LoRA（低秩适配）是参数高效微调方法，冻结预训练权重，只训练少量低秩矩阵。大幅减少训练参数量，在消费级 GPU 上即可微调大模型。

RAG（检索增强生成）将外部知识库检索结果与问题拼接输入模型，缓解大模型知识陈旧和幻觉问题。检索器（向量检索+关键词）+ 生成器（LLM）。

大模型幻觉（Hallucination）指生成看似合理但实际错误的内容。缓解方法：RAG、约束解码、事实校验、提示工程。

## 十二、强化学习

强化学习通过智能体（Agent）与环境交互，根据奖励（Reward）学习最优策略。核心要素：状态（State）、动作（Action）、奖励（Reward）、策略（Policy）。

Q-Learning 是值迭代方法，学习动作价值函数 Q(s,a)。Deep Q-Network（DQN）用神经网络近似 Q 函数，结合经验回放和目标网络，首次在 Atari 游戏上超越人类。

策略梯度（Policy Gradient）直接优化策略网络，通过采样轨迹估计梯度。PPO（Proximal Policy Optimization）是目前最常用的强化学习算法，稳定且高效。

## 十三、工程实践

过拟合与欠拟合的判断：训练集和验证集都差 → 欠拟合（高偏差），需更复杂模型或更多训练；训练集好验证集差 → 过拟合（高方差），需正则化或更多数据。

特征缩放：不同特征量纲差异大时需归一化或标准化。标准化 z = (x-μ)/σ，使特征均值 0 方差 1。对基于距离的算法（KNN、SVM）和梯度下降优化的算法重要。

类别不平衡处理：过采样（SMOTE）、欠采样、调整类别权重、使用合适指标（F1、AUC 而非准确率）。

模型可解释性：LIME（局部可解释模型）、SHAP（SHapley 值）、注意力可视化。理解模型决策依据，增强可信度。

## 十四、数学基础

线性代数：向量、矩阵运算、特征值分解、奇异值分解（SVD）。是机器学习算法的数学基础。

概率论与统计：贝叶斯定理、概率分布（高斯、伯努利、多项式）、最大似然估计（MLE）、最大后验估计（MAP）。

微积分：梯度、偏导数、链式法则。是反向传播和优化的数学基础。

信息论：熵（Entropy）衡量不确定性，交叉熵衡量分布差异，KL 散度衡量分布距离。
